# 게임 디자인 문서 — Make A Car

## 컨셉

- 짧은 제한 시간 안에 **주변 환경에서 자동차 재료를 파밍**하고, 그 재료로 차를 조립한 뒤 레이싱으로 승부한다.
- **유저의 상상력이 핵심**: 자동차 재료는 무엇이든 가능하다. 바퀴가 동그랄 필요 없다 — 네모난 플라스틱 블록을 바퀴 자리에 달아도 된다. (젤다 왕눈 차량 조립의 자유도 참고)
- **아트 디렉션**: 토이스토리 같은 장난감 그래픽. 진짜 레이싱카가 아니라 나무토막/장난감 차처럼 보여야 한다. 밝은 원색, 토온 셰이딩, 단순한 도형.
- **데모 맵**: 장난감이 가득한 아이 방(토이스토리 세상). 도형이 복잡하지 않으면서 창의성을 발휘하기 좋다.

## Phase 1 — 재료 파밍 (구현됨)

- 제한 시간 **N초**(현재 120초) 동안 맵을 돌아다니며 재료를 파밍한다.
- **시점**: 1인칭
- 재료를 주워서 자신의 **차고지**(노란 매트 영역)로 옮긴다.
- 시간 종료 시 **차고지 안에 있는 재료만** 사용 가능하다.
- (멀티플레이) **다른 사람 차고지에서 훔치기 가능** — 종료 순간의 위치만 판정하므로 자연스럽게 성립한다.
- 파밍 가능한 재료는 맵마다 다르다. 데모 맵의 파츠 카탈로그:

| 파츠 | 형태 | 특성 |
| --- | --- | --- |
| 대형 차체 블록 | 큰 직육면체 | 차체(섀시) 후보. 가볍고 큼 |
| 나무 블록 / 판자 | 정육면체 / 납작한 판 | 범용 구조재. 중간 무게 |
| 장난감 바퀴 | 원기둥 | 정석 바퀴. 밀도 높음(무거움) |
| 실패(스풀) | 원기둥 | 가벼운 바퀴 대용품 |
| 고무공 | 구 | 통통 튐. 창의적 바퀴 후보 |
| 블록 브릭 / 도미노 | 작은 직육면체 | 장식·무게 조절용 |

## Phase 2 — 자동차 조립 (예정)

- Phase 1에서 모은 재료로 **1분 안에** 차를 조립한다.
- **시점**: 1인칭 (차고지 앞 조립대)
- **차종은 4륜구동**.
- **모터는 기본 제공**: 모터 자체로는 차가 움직이지 못하고, 모터에 "바퀴 역할을 할 것"을 붙여야 움직인다.
- 기본 조립 시나리오: 파밍한 대형 블록(차체)에 모터 4개를 달고 → 각 모터에 파밍한 파츠(바퀴)를 붙인다.
- 어떤 파츠든 바퀴 소켓에 붙일 수 있다 — 네모 블록 바퀴, 공 바퀴 모두 허용.

## Phase 3 — 레이싱 (예정)

- 조립한 차로 레이싱 대결. **시점**: 3인칭
- **속도 구현이 핵심**: 차가 가지각색이고 파츠마다 무게가 다르다.
  - 모터 출력은 모두 동일 → 파츠의 모양·무게·바퀴 형태가 성능을 결정한다.
  - 무거운 차는 가속이 느리고, 각진 바퀴는 덜컹거리고, 둥근 바퀴는 잘 구른다 — 물리엔진이 자연스럽게 만들어내는 차이를 그대로 게임성으로 사용.
- 물리엔진 기반 상호작용(충돌, 찌그러짐 등) 검토.

## 게임 루프 요약

```
[Phase 1: 파밍 N초] → [Phase 2: 조립 60초] → [Phase 3: 레이싱] → 결과
```

## 멀티플레이 (장기)

- 여러 유저가 같은 방에서 동시에 파밍 → 재료 경쟁, 차고지 훔치기
- 같은 트랙에서 동시 레이싱
- 데모는 1인 플레이 기준으로 먼저 완성하고, 이후 네트워크 동기화를 얹는다.
